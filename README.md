# Hangman Game

A simple Hangman game built with plain HTML, CSS and JavaScript.

## How to play

Open `index.html` in any modern browser and start guessing letters. You can
also serve the folder from any static web server.

Live demo: https://jguzmsan.github.io/cursor-test-repo/

## Features

- Random word every game
- On-screen keyboard plus physical keyboard support
- Remaining attempts counter
- Progressive hangman drawing
- Win / lose states with restart button
